# docs/ — README 用の画面写真

## 1. このディレクトリの役割

| ファイル | 役割 |
|---|---|
| `images/*.png` | README に載せる画面写真（一覧・⋮メニュー・再生画面・⚙設定・フォルダへ移動） |
| `make_screenshots.py` | 上の写真を撮り直すスクリプト |

写真には **個人の動画を写さない**。`make_screenshots.py` はフリー素材（Blender Foundation のオープンムービー
Big Buck Bunny・Sintel。どちらも CC BY 3.0。クレジットは README）を切り出してサンプル動画を作り、
一時フォルダをライブラリにした専用のアプリ（使用中のアプリとは別の二重起動防止名・ポート・データ置き場）を起動して、WebView2 の開発者ツール用プロトコルで操作し PrintWindow で撮る。

```bat
.venv\Scripts\python docs\make_screenshots.py
```

撮影中は 30 秒ほどウィンドウが表示される。音は出さない（ミュート）。
素材は初回だけダウンロードする（Big Buck Bunny は zip 配布のため約 275MB）。切り出した動画は
`%TEMP%\mlt_screenshot_clips` にキャッシュして次回から使い回す。

素材を選ぶときの注意: 気味の悪い映像（合成図形・シュールな作風）は避け、明るく親しみやすい場面にする。
ライセンスがあいまいな素材（CC BY と CC BY-SA の情報が食い違うもの等）は使わない。

## 2. 現在の問題点

- 撮影は Windows のみ（PrintWindow・WebView2 を使うため）
- 画面の構成（カードの順番など）が変わると、撮りたい場面とずれることがある。撮り直したら必ず目で確認する

## 3. 撮り直すときの手順

1. 画面を変えたら `make_screenshots.py` を実行する
2. `images/*.png` を開き、個人の情報（自分の動画・フォルダ名・パス）が写っていないこと、
   撮りたい状態（メニューが開いている等）になっていることを確認する
3. 写らない・ずれる場合は、スクリプトの待ち時間やセレクタを直す（アプリ本体は触らない）
